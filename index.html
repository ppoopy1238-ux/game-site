Tab disguise

Change the name and icon shown on the browser tab so it looks like another site.

Picking a preset fills in the name and icon. Press Apply disguise to use it. Reset tab goes back to Google Drive.

When on, opening the site also opens an about:blank tab that holds it, and your first tab switches to google.com. Applies the next time you open the site.

Search

Controls the search box on the Home page.

Paste the base URL of your deployed Sublevel Cloudflare Worker. The Worker handles login, /search and /browse. Save it here after deployment.

Only used if no Worker URL is configured. Supports %q for search words or %s for the complete search URL.

Google AI

Powers the AI page. Get a free key at aistudio.google.com. It is saved only in this browser, so don't share a copy of the site that has a key saved in it.

Any model name your key can use. Google renames models over time, so change this if you get a "model not found" error.
